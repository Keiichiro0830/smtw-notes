2026-04-15 知的鍛錬の原理と方法は古びない

私の講義やゼミに参加される受講者の目的は、まずその科目の内容を理解することにあります。

最初の段階では、受講者の関心は「何を学ぶか」、つまり知識や情報に向かいます。

ところが、一定の水準に達した受講者の中には、単位取得後に「これで終わり」ではなく、

「先生はどのように考えているのか」「その思考の方法を知りたい」

と関心の軸が移る人が現れます。

これは単なる好奇心の変化ではありません。

「何を」から「どのように」へと関心が移ることは、知的成熟の質的な飛躍です。

知識の獲得から、思考の構造そのものへの関心へと進むからです。

そして興味深いことに、こうした受講者は卒業後、独創的な事業を立ち上げて成功していく傾向があります。

私自身の長年の経験からも、この「思考への関心の転換」が、その後の飛躍の重要な兆しであることを強く感じています。それは偶然ではないと思います。そこには明確な構造的理由があると思います。事業を起こすという行為は、本質的に「まだ存在しない問いを自分で立てる」ことに通じます。既存の知識を適用するだけでは新しい事業は生まれない。市場の定説や常識を疑い、自分の目で見て、自分のリスクで判断を下す。これはまさに「思考の方法」を自分のものにした人間にしかできないことです。

これはAI時代においてますます決定的な差異になります。AIの出力をそのまま使う人間は「内容の消費者」にとどまる。しかし、AIを素材として扱いながら自分の判断軸で切り直せる人間――それが独創的な事業を生む側に立てる。知的鍛錬塾が育てようとしているのは、まさにその力です。

私自身は自分の思考方法について深く考えたことがありませんのでそれを他人に伝授するといったことはできません。そこで、このメルマガでは竹内均氏の『私の知的鍛錬法』（1980年、徳間書店）を参考書の一つにしました。これは「わが国屈指の地球物理学者が、50年間で磨き上げた知的鍛錬の技術！・・・徹底した知的鍛錬を一日も休まず続けてきた著者が、その秘伝を全面公開」した本です。

竹内氏は自らの知的鍛錬を意識的に「方法」として言語化した稀有な人です。地球物理学という一つの分野で世界水準の仕事をしながら、同時に『Newton』の創刊編集長として科学の啓蒙にも携わり、膨大な著述を続けた方です。その生産力の背後にある方法を、本人が「秘伝を全面公開」という形で執筆しています。

この本の裏表紙には次の紹介があります。「人生の知的羅針盤を求める人に贈る英知の結晶！！日常生活のあらゆる寸暇を利用して、自らを知的に鍛えあげる方法がここにある。その方法は？どうしたら長続きさせることができるか？いかに磨きあげるのか？そのノウハウを知ればぶばり新しい知的人生の道が開ける。人より数歩先んずる知的鍛錬の神髄が身につく本！」とあります。

注目すべきは、ここで強調されているのが「才能」や「天賦の知性」ではなく、「方法」と「継続」だという点です。「日常生活のあらゆる寸暇を利用して」「どうしたら長続きさせることができるか」――竹内氏が知的鍛錬を、特別な環境や才能の問題ではなく、日常の技術と習慣の問題として捉えていたことがよく表れています。

なぜ竹内氏に着目するのか？

第一に、竹内氏を選ぶ理由は「成功者だから」ではありません。成功者は確かに大勢いるが、自分の知的方法を意識的に言語化し、再現可能な形で公開した人は極めて少ない。多くの成功者の自伝や方法論は、結果から逆算した事後的な物語にすぎない。竹内氏の場合、50年間の実践の中から方法を抽出しており、その具体性と誠実さにおいて類書と一線を画しています。

第二に、竹内氏は「知的鍛錬」という言葉を使っている点が重要です。知的鍛錬塾の名称と直接響き合う。これは単なる偶然の一致ではなく、私が塾の理念を受講者に伝えるための最適な導入テキストとして機能するということです。

第三に、メルマガで紹介するのは竹内氏の方法を「正解」として提示するためではない。一つの具体的で明確な方法論を共通の土台として置くことで、受講者が「自分ならどうするか」「自分はここが違う」と考える起点を与える。比較対象がなければ自分の思考方法を意識することすらできない。竹内氏の本はその触媒です。

この本の目次と小見出しは次のとおりです。

第1章「知的生きがいのために」――人生の目的設定と知的生活の動機づけ。福沢諭吉、本田宗一郎、大橋巨泉ら多様な人物の生き方を参照しながら、逆算式仕事術や「新エンゲル係数」といった独自の指標で知的生きがいの指針を示す。

第2章「断片の論理」――日常の断片的な時間を知的鍛錬に活用する具体的方法。完全睡眠、早朝仕事、通勤時間読書、「ながら族」的瞬間集中など、生活設計としての知的鍛錬を論じる。

第3章「第三世代の学問」――独創性の本質を探る。デカルト、ポアンカレ、ウェゲナー、ダーウィンの方法を分析し、インスピレーションや美的直感が学問においてどう機能するかを考察する。

第4章「読み」の秘伝――読書法の実践論。百科事典の活用、オーバーライン式読書術、英語学習法、図書館の使い方など、情報摂取の具体的技術を展開する。

第5章「書き」の秘伝――文章術の実践論。テープレコーダーを活用した口述法、一文一主語の原則、主語と述語の対応、要約力の訓練など、アウトプットの技術を体系化する。

第6章「雑学のすすめ」――専門を超えた知的関心の広げ方。データバンクづくり、外国旅行による自己開発、ハプニング精神など、知的生活の幅と柔軟性を説く。このメルマガでは上の目次と小見出しを共有できれば十分です（これは目次と小見出しから生成AI(Claude)が推測したものです。本文を読めば異なる像が浮かぶ可能性があります）。

今では、百科事典はインターネット検索に、テープレコーダーは音声入力アプリに、図書館は電子書籍やデータベースに、それぞれ置き換わった。道具は完全に変わりました。しかし、竹内氏がそれらの道具を通じて実践しようとしていた「構造」は変わっていません。

たとえば「断片の時間を活用する」という原理は、通勤時間にスマートフォンで情報を摂取する現代人にもそのまま当てはまる。むしろ道具が便利になった分、断片時間の使い方が惰性に流れやすくなっている。

竹内氏の時代には、限られた道具を意識的に使いこなすしかなかった。その意識性こそが鍛錬の核心でした。

ここにAI時代との接点があります。生成AIは百科事典やテープレコーダーどころではない強力な道具です。しかし道具が強力になればなるほど、「その道具を使って何をするのか」という問いが重要になる。竹内氏が百科事典を「ひく」のではなく「読む」と言ったのと同じように、AIも「使われる」のではなく「使う」という主体性がなければ、知的鍛錬にはならない。

道具は古びても原理は古びない。

2026-04-19 AIは本当に「言葉の意味」を理解しているのか — 「確率的オウム」論争

こんな経験はないだろうか

ChatGPTに調べものを頼んだり、Claudeに文章の相談をしたりすると、驚くほど自然な日本語が返ってくる。

質問の意図をちゃんと汲んで、的確に答えてくれる。

「これ、本当にAIが書いてるの?」と思うほど人間らしい。

ここで一つ、立ち止まって考えてみたい。

AIは、自分が書いている言葉の「意味」を、本当に分かっているのだろうか?

「分かっているに決まっている、こんなに自然に答えてくれるのだから」と思うかもしれない。あるいは逆に、「いや、AIはただの機械でしょう。意味なんて分かっていないよ」と思うかもしれない。

どちらが正しいだろうか？

実は今、世界中の研究者が、まさにこの問いをめぐって活発に議論している。

そして驚くべきことに——まだ答えは出ていない。

この「答えが出ていない」ということ自体が、とても重要である。今日はその話をしたい。

「確率的オウム」という言葉

2021年、アメリカの研究者たちが一本の論文を発表した。そこで彼らはChatGPTのようなAI(専門的には「大規模言語モデル」、英語の頭文字をとって LLM と呼ぶ)を、こう呼んだ。

「確率的オウム」(stochastic parrots)

オウムは人間の言葉を真似してしゃべる。「おはよう」と言われたら「おはよう」と返す。でも、オウムが「おはよう」の意味を理解しているとは、誰も思わない。ただ音を真似しているだけだ。

研究者たちが言ったのは、こういうことだ。LLMは膨大な量の文章を読み込んで、「この単語の次にはこの単語が来やすい」という確率を計算しているだけだ。だから、人間の質問に対して「それっぽい」答えを返せる。でも、それは確率的に最もありそうな単語を並べているだけで、意味を理解しているわけではない—ちょうど、すごくものまねのうまいオウムのように。

この見方をする人たちの根拠は、こうだ。意味を理解するためには、言葉と「現実の世界」がつながっていなければならない。「リンゴ」という言葉は、本物のリンゴ—赤くて、丸くて、かじれば甘酸っぱい、あの果物—とつながっているからこそ意味を持つ。だがLLMは、文字情報しか見ていない。本物のリンゴを見たことも、触ったことも、食べたこともない。それなのに「リンゴ」という言葉の意味を本当に理解できるはずがない、と。

これは、なかなか説得力がある主張だ。

「ちょっと待って」と言う研究者たち

しかし、これに「ちょっと待ってほしい」と言う研究者たちもいる。

その代表が、Brown大学のエリー・パブリック(Ellie Pavlick)という研究者だ。彼女が2023年に発表した論文は、この論争において非常に重要なものとして読まれている。

パブリックの主張を、できるだけ平たく言うと、こうなる。

「LLMが意味を理解していないと決めつけるのは、まだ早すぎる」

なぜか。彼女が指摘するのは、私たちがLLMを判断するとき、ほとんどの場合、AIの振る舞い(出力された答え)だけを見ている、ということだ。AIがおかしな答えを返した。だからAIは理解していない—こういう論じ方をしている。

でも、考えてみてほしい。例えば、テストで間違えた友達がいたとして、「お前は何も分かっていない」と言い切れるだろうか? もしかしたら、ちゃんと分かっているけれど、ケアレスミスをしただけかもしれない。あるいは、本人なりの考え方があって、たまたまテストの答えとは違っていただけかもしれない。

人間の場合、私たちは「外から見える振る舞い」と「頭の中で実際に起きていること」は別物だと知っている。だからこそ、表面の答えだけで判断はしない。

パブリックが言うのは、AIに対しても同じ態度をとるべきだ、ということだ。AIの内側で何が起きているかを、ちゃんと調べないといけない。それを調べずに「AIは理解していない」と決めつけるのは、フェアじゃない。

AIの「頭の中」を覗いてみると

ここからが面白い。

ここ数年、研究者たちはLLMの「頭の中」——つまり、AIの内部で何が起きているか——を実際に調べる方法を開発してきた。これは「機械論的解釈可能性」という研究分野で、まだ生まれたばかりだが、急速に発展している。

そして調べてみると、驚くようなことが分かってきた。

例えば、LLMの内部には、特定の概念に反応する「部分」がある。有名なのは「猫ニューロン」と呼ばれるもので、AIが猫について考えているとき、特定の場所が活発に働く。文法構造を表現している部分も見つかっている。動詞、名詞、過去形、現在形——こうした概念に対応するパターンが、AIの内部に存在しているらしい。

もっと驚くのは、これらの内部表現を実験的にいじると、AIの答えが予測通りに変化することだ。例えば「猫」を表している部分を「犬」を表す部分に書き換えると、AIは犬についての話を始める。これは、その内部表現が、ただの飾りではなく、本当に意味のある働きをしていることを示している。

つまり、AIの内部には、人間が「意味を理解する」ときに使っているのと似たような構造が存在しているかもしれない、ということである。

第2章 例題「長さと幅と高さが知れている直方体の対角線を求めよ。」

具体的な例から始めよう。中学・高校で学ぶ典型的な数学の問題である。

長さを a、幅を b、高さを c とする直方体を考える。その対角線の長さを求めよ。

解法は二段階の三平方の定理の適用である。まず底面の対角線を求める。底面は長さ a、幅 b の長方形なので、その対角線は √(a² + b²) となる。次に、この底面の対角線と高さ c が直角を成すので、もう一度三平方の定理を適用すると、直方体の対角線 d は次のように求まる。

d = √(a² + b² + c²)

たとえば a = 3、b = 4、c = 12 の場合、d = √(9 + 16 + 144) = √169 = 13 となる。

これは「三次元のピタゴラスの定理」とも呼ばれる、よく知られた結果である。日本の高校生で数学を学んだ人であれば、多くがこの問題を見た瞬間に解法を思いつくだろう。

AIにこの問題を入力すると、人間と同じように、ほぼ瞬時に同じ答えを返す。問題は、AIがこの答えをどのように「導いた」のか、ということである。AIは本当に三平方の定理を理解して、それを二回適用したのだろうか。それとも何か別のことが起きているのだろうか。この問いに答えるために、AIの学習の仕組みを見ていく必要がある。

第3章 AIの事前学習のポイント:文書データセットの「字面の表層の統計的パターン」を抽出して記録する

ここで重要なのは、AIが学習しているのは何か、という点である。AIが訓練の過程で実際に最適化しているのは、「与えられた文脈に続く次の単語(正確にはトークンと呼ばれる単語の小さな単位)を予測する精度」である。膨大なテキストの中から、「この単語の並びの後には、こういう単語が続きやすい」という統計的なパターンを抽出して、AI内部の数千億個の数値(重みと呼ばれる)に記録していく。

つまりAIの事前学習とは、文書データセットの字面の表層の統計的パターンを抽出して記録すること、と整理できる。

これはAIの能力を貶めるための表現ではなく、技術的に正確な記述である。AIの内部に「思考」や「意図」が宿っているわけではない。あるのは、字面の統計的パターンを記録した巨大な数値の網である。AIがテキストを生成するとき、入力された文字列に対して、訓練で記録されたパターンに従って、次に続くべき単語を一つずつ予測していく。それを繰り返すことで、長い文章が生み出される。

この事実は、AIの能力と限界の両方を理解する出発点になる。

第4章 上の例題が入力された後、AIは字面の統計的パターンを把握したか?

人間が「2 + 3 は?」と問われた瞬間、考えるまでもなく「5」が頭に浮かぶ。あるいは「桜」と聞いた瞬間、春、ピンク、入学式、といった関連するイメージが一気に思い浮かぶ。これと似たことが、AIの中でも起きている。

つまりAIは、問題を見て一から考え始めたわけではない。過去に大量に見た同じような問題と解答のパターンが、入力に反応して自動的に立ち上がった——これが起きていることの本質である。

第5章 AIにとっての難問とは?:字面の統計的パターンで攻略できない部分

しかし、ここから話が反転する。

事前学習が抽出して記録するのが字面の統計的パターンであり、AIの入試解答能力もそのパターンの呼び出しによって成立しているのだとすれば、字面の統計的パターンに還元できない部分には、AIは原理的に手が届きにくい、ということになる。

第1章で触れた、現代文の中崎学氏の指摘——「比喩や皮肉などの複雑な文脈を読み取る難問では合格にはほど遠い」——は、まさにこの境界を指している。

皮肉や比喩、文の裏の意味とは、字面の意味と書き手の意図がずれている現象である。「素晴らしいパーティだったわ」という発話が、字面通りの賛辞ではなく、不満や軽蔑を表していることがある。この種の意味は、字面の統計だけからは捉えにくい。なぜなら、書き手の意図は字面の背後にあるものであり、字面そのものに直接書かれているわけではないからである。

歴史の論述でも同じ問題が現れる。「なぜAという出来事がBという結果を引き起こしたのか」を論じるためには、複数の要因を重み付けし、因果関係を構成する力が必要である。これは個々の歴史的事実を覚えていることとは別の能力である。AIは事実は大量に持っているが、それらを問いの構造に沿って因果的に再配列する能力は、字面のパターンの組み合わせとして近似的にしか持っていない。

したがって、AIの能力には、おおよそ三つの領域がある。

第一に、訓練データに同じ字面のパターンが豊富に存在する領域。直方体の対角線のような典型問題、定型化された皮肉、よく知られた比喩。AIはここでは強い。

第二に、字面のパターンに近いが、文脈の引力との間に競合が生じる領域。ここでAIは時々失敗する。たとえば、強い否定表現が周囲の肯定的な文脈に埋もれていると、AIはそれを肯定的な意味に読み替えてしまうことがある。読めているように見えて、実は表面的にしか捉えていない。

第三に、字面のパターンに頼れない、本当に新しい文脈で書き手の意図を読む領域。具体的な人物の具体的な状況での皮肉、未知の社会的文脈での含意、独自の文学作品での比喩。ここではAIはかなり弱い。頼るべきパターンが乏しいからである。

入試問題で言えば、現代文の問題のうち、定型的な問題は第一の領域で扱える。少しひねりがある問題は第二の領域で時々失敗する。本当に深い読解を要求する問題は第三の領域で安定的には解けない。日経新聞の記事が描いていた「最高水準で合格しているように見えるが、肝心な読解では合格にはほど遠い」という不均衡は、この三層構造の現れである。

第6章 おわりに

AIが大学入試で首席合格相当の成績を収められるのは、入試問題の多くが字面の統計的パターンで攻略可能な範囲にあるからである。これは、AIが「考えている」からでも「理解している」からでもない。膨大なテキストから抽出された字面のパターンが、入試問題という形式と高度に整合しているからである。

このことは、AIの能力を示すと同時に、入試制度そのものへの問いを投げかける。最難関と呼ばれてきた入試の多くが、字面の統計的パターンで攻略可能な範囲に収まっていたという事実は、入試がこれまで何を測ってきたのかを再考させる。

そして同時に、AIには手が届かない領域が確かに残っていることも見えてくる。文の裏の意味、書き手の意図、複雑な因果関係の構成——これらは字面のパターンに還元しきれない、人間の読解と思考の核心部分である。

AIが入試で高得点を取る時代において、人間にとって本当に育てるべき力は何か、という問いは、ますます重みを増している。

2026-05-03 自分のもとめる知識を探す方法

「私たちはまず第一に、百科事典をうまく使う技術を身につけなければならない。私たちが知るべきことの大部分は百科事典に記されている。したがってあることについての知識を得たい場合には、まずは百科事典にあたってみることである。」（竹内均.1980.『私の知的鍛錬法』徳間書房、125ページ）

これは知識探索の方法論についての議論で、現代のAI/LLM(大規模言語モデル)をめぐる議論と直接結びつく古典的な見解です。この一節は、知識探索における「まず信頼できる体系化された参照枠から出発せよ」という方法論的原則を表現しています。これは現代の文脈で読み直すと、極めて示唆に富みます。

1. AIと百科事典の構造的類似

LLMは、ある意味で究極の百科事典として理解できます。竹内氏（1980）が百科事典に求めた機能 — 体系化された知識への迅速なアクセス、自分で一から調べる労力の節約、信頼できる出発点の提供 — は、まさに今日多くの人がChatGPT,Gemini,およびClaudeに求めているものです。

しかし、ここに決定的な違いがあります:

  • 百科事典: 専門家による署名付きの記述、出典が明示され、編集者の責任が明確で、項目が固定された参照枠（決まった内容が、決まった場所に、変わらずに置かれている知識のまとまり）。
  • LLM: 出典不明の統計的合成、確率的に生成される回答、責任主体が曖昧、同じ質問でも異なる回答が返る。

「ChatGPTは説得力ある形で誤った情報を生成する」という警告（Van Dis et al. 2023）があるように、LLMは百科事典の外見を模倣しながら、その基盤である検証可能性と固定性を持たない点が問題視されています。

２. 「まず百科事典に」という方法論の現代的妥当性

竹内氏の主張を現代に翻訳すると、次のような原則になるでしょう:

新しいトピックを調べるとき、まず信頼できる体系化された出発点(百科事典/教科書/レビュー論文)に当たれ。検索エンジンやAIに直接問うのは、その後にせよ。

この原則は、最近の研究（Van Dis et al. と Kusumegi et al.）から見ても、現代でこそむしろより重要になっているかもしれません。理由は:

① 基盤知識なしにLLMを使うと、誤りに気づけない — Van Dis et al. が懸念した「権威ある散文に騙される」問題への対処策。

②基盤知識があれば、LLMを批判的に活用できる — Kusumegi et al. のいう「ステータス・マーカーへの退却」を防ぐには、内容そのものを評価できる読者が必要。

③百科事典的な体系性は、LLMの確率的生成では代替できない — Agrawal et al. のいう「人間の判断」の前提条件として、体系化された基盤知識が不可欠。

つまり竹内氏の素朴に見える教えは、AI時代において「LLMに問う前に、まず百科事典で土台を作れ」という、極めて先見的な方法論として復活する余地があります。

3．1980年という時代の文脈

1980年は、インターネットも検索エンジンも存在せず、百科事典が知識アクセスの最高位の道具だった時代です。竹内氏が「まず第一に、百科事典をうまく使う技術を身につけなければならない」と書いたとき、それは当時の知的生産における最も合理的な助言でした。当時の研究者・学生にとって、百科事典は:

  • 専門外の概念を素早く把握する最良の入口
  • 信頼できる執筆者(各分野の第一人者)による署名付き解説
  • 索引と相互参照によって関連知識へ展開できる体系
  • 何より家庭や図書館で手の届く範囲にある唯一の包括的知識源

竹内氏の助言は、当時の物理的・制度的環境に最適化された、極めて実践的な方法論でした。

竹内均という人物の重要性

竹内氏が興味深いのは、彼が自然科学者でありながら、知識の社会的伝達に深く関わった人物だという点です。『Newton』の編集長として、彼は最先端の科学を一般読者に届ける仕事を生涯続けました。つまり彼にとって「知識を得る」とは:

  • 専門家同士の閉じた会話ではなく、広く社会に開かれた営み
  • 専門の壁を越えて、異分野の知見を吸収する活動
  • 体系化された出発点から、自分なりの理解を構築するプロセス

このような立場の人物が「まず百科事典」と説いたことは、単なる便宜的助言ではなく、知識へのアクセスの民主化と、体系性の重視という二つの価値の表明でした。

４．現代の議論との接続

現在懸念されることは、ある意味で竹内の前提が崩壊しつつあるという事態です（Van Dis et al. (2023) や Kusumegi et al. (2025)など）:

  • 竹内氏の時代、「百科事典」は専門家の責任ある執筆を意味した。LLMの時代、出典が消える。
  • 竹内氏の時代、「まず百科事典に当たる」訓練は知的生活の前提だった。LLM時代、その訓練自体が省略されかねない。
  • 竹内氏の時代、言語能力と知識能力は分離できなかった。LLM時代、洗練された文章は知識を保証しない(これがまさにKusumegi et al. の発見)。

しかし同時に、竹内氏の方法論にはLLM時代にこそ復活すべき要素があります。Agrawal et al. (2026) が論じた「人間の判断は依然として不可欠」という主張は、形を変えた「まず百科事典に当たれ」という助言でもあります。つまり:

AI に問う前に、自分の中に体系的な基盤知識を構築せよ。さもなくば、AI の出力を批判的に評価することができない。

竹内均なら今、何と言うか

竹内氏が2026年に存命であれば、おそらく次のように言うのではないでしょうか — これは推測ですが、彼の知的姿勢からの自然な延長として:

「LLMを使うこと自体は構わない。しかしLLMを使う前に、信頼できる教科書、レビュー論文、専門書、つまり人間の専門家が責任を持って体系化した出発点に当たる訓練を欠かしてはならない。LLMはその後の探索を加速する道具としては優れているが、出発点の代替にはならない。なぜなら、出発点なしにLLMを使えば、何が正しく何が誤っているかを判断する基盤そのものを失うからである」

これは竹内氏自身の言葉ではありませんが、彼の1980年の助言を、百科事典の社会的位置が変容した今に翻訳すると、こうなるのではないかと思います。

５．現代ではWikipediaも利用できる

竹内氏が1980年に書いた助言を現代に翻訳する上で、Wikipediaは決定的に重要な存在です。

「Wikipediaは竹内の言う「百科事典」の正統な後継か？」

ある意味で完全に正統な後継であり、別の意味では根本的に異質な存在でもあります。両面を見ていきましょう。

正統な後継としての側面

竹内氏が百科事典に求めた機能のほとんどを、Wikipediaは継承しています:

  • 体系化された出発点:任意のトピックについて、構造化された概観を提供する
  • 相互参照による展開:ハイパーリンクによって、紙の索引以上に流動的に関連項目へ移動できる
  • 信頼できる出典への橋渡し:良質な記事は脚注で原典に誘導する
  • アクセスの民主化:1980年の百科事典が高価で物理的に重い書物だったのに対し、Wikipediaは無料・即時・どこからでも

特にこの最後の点 — アクセスの民主化 — について、竹内氏は確実に喜んだはずです。彼が『Newton』を通じて追求した「科学を一般読者に届ける」という生涯の使命は、Wikipediaが体現するオープンな知識共有と思想的に深く通底しています。

根本的に異質な側面

しかし、いくつかの本質的な違いも存在します:

①執筆者の責任構造の違い

1980年の百科事典(平凡社『大百科事典』、ブリタニカなど)の項目には、各分野の権威ある専門家が署名して執筆していました。読者は「誰がこれを書いたか」を知ることができ、その人物の業績を通じて信頼性を評価できました。

Wikipediaは原則として匿名の集合的編集です。これは長所(誰でも誤りを修正できる)と短所(責任主体が拡散する)の両方を持ちます。竹内氏のような研究者であれば、この点について両義的な評価を下したかもしれません。

②完成された記述 vs. 進行中の対話

紙の百科事典は、ある時点で編集者が完成と判断した記述でした。一方Wikipediaの記事は常に進行中であり、特に論争的なトピックでは編集合戦の最中の状態を読者が見ることもあります。

③「魅力的な寄り道」の質の違い

ポプラ社*が指摘した紙の百科事典の「魅力的な寄り道」 — 同じページに偶然並んだ無関係な項目との出会い — は、Wikipediaのハイパーリンク経由の探索とは質的に異なります。Wikipediaの寄り道は意味的に関連した項目へ向かう傾向が強く、紙の百科事典の物理的な隣接性が生む偶然性は失われています。

*https://kodomottolab.poplar.co.jp/hello-poplardia/download/dl/shidouan20211223.pdf

６．「まず Wikipedia、その後 LLM」という現代版の方法論

現在のAIへの懸念を考えると、竹内氏の1980年の助言の現代版は次のようになるでしょう:

新しいトピックを調べるとき、まず Wikipedia で体系化された出発点を得よ。脚注で示された原典に当たれるならば、当たれ。その上で初めて、LLM を使って疑問点を掘り下げたり、複数の情報を統合させたりせよ。決して LLM の回答を最初の出発点にしてはならない。

この順序が重要なのは、次の理由からです:

1. 基盤知識の確立:Wikipedia で得た体系的理解が、LLM の出力を批判的に評価する基盤になる

2. 誤検出能力の獲得:Wikipedia の記述と LLM の回答を照合することで、LLM の幻覚(hallucination)に気づける

3. 出典の確保:Wikipedia の脚注は学術的引用に使えるが、LLM の出力はそのままでは引用できない

なお、ウィキペディアは「信頼を築く」ために次の３つの方針に基づいて編集されています（https://wikimediafoundation.org/news/2025/10/02/the-3-building-blocks-of-trustworthy-information-lessons-from-wikipedia/）。

  • 中立的な観点: Wikipedia の記事は、可能な限り偏りなく、公平に情報を提示しなければならない。
  • 検証可能性: すべての情報は、読者自身が確認できる、公開された信頼できる情報源に基づかなければならない。
  • 独自研究の禁止: Wikipedia は個人的な意見や新しい解釈を掲載する場ではなく、信頼できる情報源で既に公開されている内容を要約するものである。

Wikipedia 自体の限界も忘れてはならない

ただし、Wikipedia にも竹内氏が当時の百科事典に対して抱いていた信頼を、そのまま付与することはできないという指摘があります:

  • 専門分野ごとの記事の質のばらつきが大きい
  • 論争的トピック(政治、宗教、最新の科学論争など)では編集者の偏りが反映される
  • マイナー言語版(日本語版を含む)は英語版と比べて記事数も質も劣ることが多い
  • 最新の研究には対応が遅れることがある

したがって、より精緻な現代版の方法論は次のようになるでしょう:

新しいトピックには、まず Wikipedia(英語版)で全体像を把握し、脚注で示された原典・教科書・レビュー論文に当たって基盤を固めよ。LLM はその上で、補助的な思考ツールとして活用せよ。

これは竹内氏の素朴な助言を現代の情報環境に適応させた形であり、同時に Van Dis et al.（2023） や Kusumegi et al.（2025） の懸念に対する実践的な対応策でもあります。

興味深いのは、竹内氏の1980年の助言が、AI時代になって陳腐化するどころか、むしろより重要になっているという点です。情報源が爆発的に増え、しかも信頼性の判定が困難になった現代において、「まず信頼できる体系的出発点に当たれ」という方法論的原則は、1980年以上に切実な助言となっているのではないでしょうか。

7.1 川口先生「この1ヶ月でのAI認識の変化」— 生成AIは新しい RStudio である

  • 川口先生はこの1ヶ月、Claude（月20ドル）と Google One Pro（NotebookLM／Gemini同梱）を本格利用。Claude Codeの「Coreワークス」モードに気づかぬまま入り、PC環境設定の自動書き換えを直前で拒否したエピソードから始まった。
  • 核心の認識転換:「生成AIは "生成AI" ではなく、RStudioと同じ プログラミングツール だ」。出力をそのまま使う対象ではなく、計算プロセスを操る道具として扱う段階に入った。
  • LLMの仕組みを口頭整理: 多層パーセプトロン × Attention = Transformer。1980年代に研究して「使えない」と判断して撤退したニューラルネットが、層数とパラメータ数を増やしたら "うまくいく" ことが発見され（誰も理由を完全には説明できないまま）、自然言語処理に応用されたのが現在のLLM。
  • Attention 機構は「遠く離れた単語との関係を重みに反映させる仕組み」と位置付け、長文翻訳のブレークスルーとして紹介。

7.2 Chen et al. (2026) "Out of the Black Box" の核心 — logprobes による不確実性の定量化（松前報告）

  • ChatGPT API に追加課金すると logprobes（対数確率）が取得できる。出力トークン (Yes / No) に対する コンフィデンス値 が 0〜1 で返る。
  • Chen らはニュース記事を数十万件、個別株への Yes/No（ポジ／ネガ）でChatGPTに分類させ、コンフィデンスを5段階に分割。最高コンフィデンスのYes銘柄をロング、最高コンフィデンスのNo銘柄をショートして組成 → シャープレシオ 5〜6超。
  • ただし論文は 取引コストと流動性制約を完全に無視。最も効果が出るのが小型・低カバレッジ株なので、実マネーを投入したらプライスを動かしてシャープレシオは下がるはず。シグナリングとしては正しい、というのが松前評。
  • 検証: Claude には logprobes は無い（クロード本人「やってません」）。Mistral は API で出るが質が悪そう。OpenAI のみが事実上の独占供給。
  • ChatGPT に直接「あなたの確信度は？」と聞く（Declared Confidence）と嘘をつく — Chen 論文で検証済み。API でローデータを取りに行かないと意味がない。
  • 結論: 単なる出力ではなく、ニューラルネットワーク内部のパラメータにアクセスして実証するアプローチが開きつつある。これが "AI Expert Scientist" の方向性。

7.7 学術研究へのインパクト — Kusumegi 論文

非英語圏の研究者がAIで生産性は上がったが、組織全体としての知的再生産は高まっていないという Kusumegi（筑波）論文。確率的オウム的に流行に乗る論文だけが増える構造を補強。

7.8 知識の探索論

  • 川口先生: 自分の求める知識をどう探すか — AIは入口便利だが泥沼にも入る。英語版 Wikipedia は自然言語処理／Transformerの必要情報を網羅。
  • 松前: 自分の知識を本物にするには「アウトプットの場」を作って外部圧をかけるしかない。AIと話している時とアウトプット作業時で頭の使い方が完全に違う。
  • 諏訪部: AIは学習データの過去の蓄積からしか出力しない。最新情報は自分で取りに行く前提。

7.9 川口先生の問い — 自分のバリューは何か

「自分はこれだけのキャリアと取材を受けているが、企業から対価をもらえる根拠は何か。確率的オウムをやっているだけならAIで代替されてしまう」 — 第2回終盤の問題提起。次回以降の議論につながる宿題。

7.10 AIは "面白さ" を作れるか

  • 諏訪部の問い: AIは「面白い研究クエスチョン」を立てられるのか。
  • 松前: 村上春樹風の文章は書けるが、「面白い」「意味あるクエスチョン」は別の何か。プロンプトの与え方次第かもしれず、まだ未解明。
  • 黒田: パフォーマティブな側面（受け手にとっての面白さ）を狙って言語生成するのは、AIには困難な領域 — おそらく人間にしかできない。
