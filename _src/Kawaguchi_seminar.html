当日の中身 —「エージェンティック時空統計学入門チュートリアル」

川口先生より当日の設計をご共有いただきました（8/1メール、8/5打合せで確定）。位置づけはLLM三部作を理解するための基礎としての時空統計学（依存性の統計学）の「入門」です。柱は①2025年の演習のポイント復習（受講されていない方がいらっしゃるため）と、②Claude Code を用いたエージェンティック（新規）の2つ。「統計モデリングのループ」を、AIチャットで人間が考えるループと、Claude Code に自律的に処理させるループの2つとして捉え、各自のPC上で実装します。

先生のお言葉では、「あなたがRでコードを書く必要はほとんどないです」。人間は「判断」に集中し、機械が「実行」を担当する、という建て付けです。

8/5の打合せでは、先生から狙いがもう一段はっきり示されました。「6時間で時空統計学の知識を増やすのなら、本を読んだほうがよほどいい。そうではなく、実際のデータの背後にあるものを探索する経験をしてもらう」——知識を増やす会ではなく、答え（ゴール）から逆算して探索を体験する会です。当日の到達点も、「どこまでAIででき、どこから統計の理解が要るのか」その境目を見つけることそのものに置かれています。

RStudio は起動しなくてよい

Claude Code が R を直接呼び出して結果を返すため、R 本体は必要ですが RStudio を開く必要はない、というのが先生の実際の運用です。先生ご自身「私の場合は Claude の言う通りにやったら RStudio を使わなかった、単に置いてあるだけだった」。とはいえ環境として両方入れておいていただくのが確実ですので、事前準備のお願いは R ＋ RStudio のままとしています。

人間の役割は「設計」に寄る

モデル選択・残差の解釈・次にどのモデルへ進むかの判断は人間が行い、コードの実行は Claude Code に委ねる——先生の資料でも、左が人間、右が Claude Code、という分担で整理されています。

AIの限界そのものがテーマになる

「線形回帰の残差を読んで、空間構造を入れるか時間構造を入れるかまで判断できるか」——ここは打合せでも議論になりました。先生も「的確な答えを出すかどうか分からないし、嘘かもしれない。それはやってみて議論しましょう」。どこまでできて、どこから human が要るのか。その境目を見つけること自体が当日の成果物という位置づけです。

8月22日との接続 —「学習」がテーマになります

8/22の研究会は、このシンポジウムの基礎にあたります。先生は8/1のメールで「以上を基礎として、10月には『投資の新しい概念』をシンポジウムで議論することになるでしょう」と書かれ、8/5の打合せではその接続をはっきり言葉にされました。

「8月22日にあるモデルを試してみて、これじゃないな、あれじゃないなという試行錯誤の部分と、企業の問題というところがアナロジーなわけです。でも両方とも最終ゴールは見えない。だから新しい投資の概念というのは、これまでのような金融工学とか金融で学んだ話ではなくて、『学習』が入ってくるわけですよ。8月22日の体験というのは、自分がどういうふうに学習をしながら、見えない構造に近づいていくかということを経験してもらうというのが最大の眼目なんです。」（川口先生・8/5）

川口先生の切り口

「ITブームとAIブームの違い」はネット上でもアナリスト等が論じていますが、先生の切り口はそれらとは異なります。7/22にご説明いただいた内容を4点に要約すると、次のとおりです。

① バリュエーション手法の世代交代

ITブーム時、赤字を垂れ流していたアマゾンのバリュエーションはDCFでは不十分で、リアルオプション（ドリフト項も確率過程としてモデル化）で評価できるという論文が出ました。現在のAIブームでは、ハイパースケーラーのバリュエーションはリアルオプションだけでは対応できず、計画資本（認知経済学）を持ち出す必要がある、という見立てです。

② 学習のパラダイム転換

回答を得るコストが急激に低下したことで、「問いのシークエンスを作ること」に価値が見出されるようになりました。

③ プラットフォームの経済学

ITブーム時には、プラットフォームの経済学はまったく見えていませんでした。

④ バブルの連鎖という歴史観

ITブームでは多くのベンチャーが死に、経済が悪化しました。それで米国は住宅バブルを起こして経済を支え、それが行き過ぎて世界経済危機になった。次のバブルはグリーンとITセクターで起こすことにして現在に至っている——という歴史の見方です。
