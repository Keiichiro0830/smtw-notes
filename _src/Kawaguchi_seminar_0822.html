参考論文 — 計画資本（planning capital）と段階的発見
Caplin (2026)『Planning Capital and Discovery-Based Learning-by-Doing』PDF 原本（NBER Working Paper No. 35349）

川口先生よりご共有いただいた論文です（Andrew Caplin, ニューヨーク大学。NBER Working Paper No. 35349、2026年6月）。フロンティアへの投資を「段階的な発見（staged discovery）」として扱うのが中心の主張で、企業は費用のかかる探究の段階を重ねながら、何を問うかを選び、その問いを費用のかかる行動として実装し、返ってきた答えを解釈していく、と定式化されます。そうして積み上がった診断的な理解そのものを資産とみなし、これを「計画資本」と呼びます。チップ・工場・データセンター・クラウド・電力契約が高く評価されるのは、すでにある物理的な能力のためだけでなく、それらが学習の痕跡を帯び、かつ次の学習を生むからだ、という読み方です。
8/22 の午後にお話ししたハイパースケーラーの企業価値と「診断的不確実性」の議論は、この論文が下敷きになっています。10/3 シンポジウムの背景文献でもあります。※ NBER ワーキングペーパーは査読前の討議用草稿です。著作権は著者に帰属します（© 2026 Andrew Caplin）。

当日の中身 —「エージェンティック時空統計学入門チュートリアル」

川口先生より当日の設計をご共有いただきました（8/1メール、8/5打合せで確定）。位置づけはLLM三部作を理解するための基礎としての時空統計学（依存性の統計学）の「入門」です。柱は①2025年の演習のポイント復習（受講されていない方がいらっしゃるため）と、②Claude Code を用いたエージェンティック（新規）の2つ。「統計モデリングのループ」を、AIチャットで人間が考えるループと、Claude Code に自律的に処理させるループの2つとして捉え、各自のPC上で実装します。

先生のお言葉では、「あなたがRでコードを書く必要はほとんどないです」。人間は「判断」に集中し、機械が「実行」を担当する、という建て付けです。

8/5の打合せでは、先生から狙いがもう一段はっきり示されました。「6時間で時空統計学の知識を増やすのなら、本を読んだほうがよほどいい。そうではなく、実際のデータの背後にあるものを探索する経験をしてもらう」——知識を増やす会ではなく、答え（ゴール）から逆算して探索を体験する会です。当日の到達点も、「どこまでAIででき、どこから統計の理解が要るのか」その境目を見つけることそのものに置かれています。

RStudio は起動しなくてよい

Claude Code が R を直接呼び出して結果を返すため、R 本体は必要ですが RStudio を開く必要はない、というのが先生の実際の運用です。先生ご自身「私の場合は Claude の言う通りにやったら RStudio を使わなかった、単に置いてあるだけだった」。とはいえ環境として両方入れておいていただくのが確実ですので、事前準備のお願いは R ＋ RStudio のままとしています。

人間の役割は「設計」に寄る

モデル選択・残差の解釈・次にどのモデルへ進むかの判断は人間が行い、コードの実行は Claude Code に委ねる——先生の資料でも、左が人間、右が Claude Code、という分担で整理されています。
