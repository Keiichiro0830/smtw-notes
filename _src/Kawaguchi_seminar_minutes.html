11.2 基調講演① 川口先生「ITブームとAIブームの比較・計画資本」

株価はバブルか

  • 物価調整済みの株価指数では、情報通信・電気機器は2000年のピークをすでに超えている。ただし2000年は約1年の垂直上昇、現在は2013年から10年以上かけた上昇で、速度が違う。不動産業の株価も上がっており、AIだけでは説明できない。
  • 企業価値を「現在の利益が永続する価値＋PVGO（成長機会の現在価値）」に分解し、PVGOが企業価値の50%超の企業を「高成長企業（バブルの可能性）」と定義。資本コストは30年国債利回り＋リスクプレミアム（10年債は日銀の政策で歪むため不使用）。
  • 日経平均構成銘柄のPVGO比率は、2000年初めに約6割 → 2010年代後半〜2022年はマイナス圏 → 2023年以降に急回復し2026年4月に49.9%、8月に38.9%。株式リスクプレミアムを4%→5.5%に動かすだけで49%→54%と50%線をまたぐため、価格指標だけではバブルか判定できない。PVGOは「真の成長価値＋価格の誤り＋利益の測定誤差＋割引率の設定誤差」を含む。
  • 3つの物差し（分母が違うので「すべて同時に正しい」）: 株価はPVGO約50%で2000年ドットコムバブルと同水準（終盤）／IT投資量（みずほのストック循環図）は米国で1995年相当、同ペースならあと約5年の余地（ただしインフレ圧力・データセンターの政治問題など当時なかった摩擦がある）／GDP比（Oxford Economics）ではAI関連設備投資が米国固定投資の27%で、1840年の英国鉄道ブームの水準＝限界。

技術の違い

  • 現在の「AI」の実態は大規模言語モデルで、文脈を条件とする確率分布から次のトークンを選ぶ装置。それでも賢く見えるのは、言語・論理に強固な統計的規則性があるため。
  • ITブームではパターンを探すのは人間（人間＋数式モデル）。AIブームではパターンを探す主体が人間からモデル自身に移った。違いは速さではなくここにある。
  • 過去の技術革新は肉体労働を代替し、人間は知的労働へ移れた。生成AIは推論・文書作成という知的作業の中核を直接代替するため、人間の「逃げ場」がない。投入時間・網羅的調査・厳密なドラフトはAIが最も安く出せるため、対価の根拠は ①課題設定（本質的な問いの定義）②責任を引き受けること ③文脈への適合（利害対立を最終合意にまとめる）へ移る。AIが答えを安くするほど「何を問うか」の価値が上がる。

計画資本（Planning Capital）

  • NYU の Andrew Caplin 氏が2026年6月に出した論文の概念（8/22ページに参考論文として掲載）。ハイパースケール時代の巨額投資は実社会で答えを出す段階的発見であり、試行錯誤から得られる学びの蓄積が企業価値の新しい源泉になる。リアルオプションは「選択肢を持つこと」に価値があるが、計画資本は「どの選択肢を試すべきか見極める力」に価値がある。
  • Amazon の例: 書籍で鍛えた需要予測・在庫判断を他カテゴリ・他国へ転用 → マーケットプレイス → 2006年にS3・EC2でAWS。近い経路ではなく書籍→小売→クラウドという遠い経路への波及。AWSは売上の約2割で営業利益の約6割。現在の第8段階は自社AIチップ投資で、2026年の設備投資は約2,200億ドル。計画発表時に株価は9%下落（診断的探求と見るか過剰コミットと見るか、市場が判断できなかった）。
  • Caplin の3要点: ①実験の対象は製品ではなく学び方そのもの ②Google は最適化がうまいのではなく、何を最適化すべきかの見極めを学んでいる ③規模の経済ではなく発見の経済。
  • 限界: 計画資本は事後にしか鮮明にならない。2006年時点でAWSが利益の主軸になると見抜いた投資家はゼロで、発見が終わるまで何が資産かわからない。歴史は説明できるが予測はできない。

需給ギャップ

  • みずほ証券のレポートでは、2030年のアナリスト予想で、需要の目安であるハイパースケーラーの営業CFは3.4倍の伸びに対し、供給される計算資源は13〜36倍。供給側が正しければ少数のハイパースケーラーが付加価値を奪う分配問題、需要側が正しければ出資・保証の連鎖で金融システムの不安定化。Oxford Economics は、急激な調整に技術が無価値だとわかる必要はなく、高まった期待への失望だけで十分と指摘。
  • 先生は結論を出さず、パネルと全体討論に委ねられました。大学・ビジネススクールも「答えを教える」だけでは将来がなく、問いを立てられる学生が必要との指摘もありました。

11.3 基調講演② 飯沼先生「市場リスクの現在地」

  • 3つのレンズ（金利・株・クレジットスプレッド）で整理。日本は9月の決定会合で利上げし政策金利1.25%、市場は来年3月までにあと2回程度の利上げを織り込む。10年国債は30年ぶりに3%へ向かい、既存債券価格の下落で地方金融機関に含み損が生じ、変動金利の住宅ローンは負担増。
  • 米国は10年国債利回りが5%超。クレジットスプレッドはIG 80bp、ハイイールド267bpで安定しており、理由は企業業績・株価が順調なことと世界的な過剰流動性。為替は円安で、介入の効果は2〜3週間〜2〜3か月で戻る「時間稼ぎ」。日米金利差拡大→円安→物価上昇→日銀利上げの循環がある。
  • ITバブルとの違い: PERはITバブル時175倍 → 現在32倍で、利益成長を伴う。フリーキャッシュフローも当時ほぼマイナス → 現在は大幅プラス。一方、調達は当時の社債中心から、SPCを多用した複雑な構造へ（WSJは「スパゲッティ」と形容）。AI投資の原資は実際には借金が増えている。
  • 循環取引: NVIDIAがクラウド・インフラ事業者や顧客に出資し、その資金でNVIDIA製品を購入させる構図が7月下旬に報じられ、株価は5%下落。8/22の議事メモ（10.12）で取り上げた論点と同じ構造です。

11.4 基調講演③ 黒田先生「AI時代における統計的因果推論の教育と研究」

  • 因果推論の基礎: 交絡変数を排除し、集団の平均因果効果を推定する。主な手法はランダム化試験、回帰不連続法（米国の飲酒解禁21歳前後の死亡率）、操作変数法（ベトナム戦争の徴兵くじ）。ボストン住宅データの古典的な回帰分析と、大気汚染規制を使う自然実験アプローチ（Chay & Greenstone 型）を対比。
  • 最近の問題提起: 主要な経済学実証研究の多くが空間的依存関係を考慮しておらず、Acemoglu の論文を含め再検証の対象になっている。今後は空間・時空間の相関を真剣に考慮する必要がある。
  • 教育: レポートで評価できず試験へ回帰し、AIを使いにくい状態で手を動かす負荷（紙のクイズ等）を大幅に増やした。研究指導: テクニカルな面はAIが教員より詳しく、教員の役割は進捗管理・励まし・「ここまでで論文になるか」の判断に移った。ただし3〜5年でAIが優れたアドバイザーになるとの見通し。
  • 質疑「AIの誤りを防止・発見する手続きは」: 完全に防ぐことは困難で、成果は人間のドメイン知識と理解の範囲でしか出ない。AIが誤ったとき「なぜ間違っているか」を人間が言語化して修正を指示する力が重要で、学生・部下の指導で鍛えられる。

11.5 パネル① 鈴木さん「ボストン住宅価格データによる空間統計の実践」

  • Windows 11・R・Claude Code で、R を一度も開かず、コードを1行も書かず、自然言語だけで完遂。R スクリプト22本・2,440行・73アウトプット、プロンプト9つ、所要約2時間（自力なら約1か月）、比較モデルは約3万パターン。基本統計 → モデル探索 → 教科書モデルとの比較 → 制約付きチューニング → 空間相関の導入 → 地図化と報告の流れ。
  • AIの暴走: 「当てはまりの良いモデル」と指示したところ、19変数・交互作用・経度まで入れ、R²は教科書モデル0.75 → 0.86に改善したが、VIF 33.6（教科書モデルは約2）の解釈不能なモデルになった。指示が曖昧な箇所では、ユーザーの理解を超える内容が出力される。
  • 対策としてAIと相談して8つの制約（交互作用なし・説明変数8〜9個・VIF5以下など）を設計。空間相関は CAR モデル（ICAR、BYM、Rur を比較して Rur を採用）で誤差項に組み込み、近接性は行政区のポリゴンで定義。所感は「免許取りたてでフェラーリに乗っている」感覚で、乗りこなせないと競争に勝てない。昨年学んだ R の使い方はほぼ意味をなさなくなったが、分析の方向性を示す力に人間の価値がある。
  • 川口先生の総括では VIF 37.7、ホールドアウトで誤差24%改善と紹介されました（鈴木さん本人の数値は33.6）。

11.6 パネル② 松前「首都圏公示地価データによる時空間統計分析」

  • 首都圏（東京・神奈川・埼玉・千葉）の公示地価 N=4,923。途中で地点が増え、新規分は価格が高いため単純平均は上昇を過大に見せる。同一地点ベースで調整した指数を作ると、急激な上昇にはならない。
  • 狙いは、8月の研究会で与えられた課題（依存の統計学として時空間モデリングを自分の言葉で説明する）。教科書の分析を同一データに全部かけて並べ、何がどう関係し、なぜ必要かを一覧で紐解いた（8/22の発表②（10.4）の発展版）。
  • 知見: 目的によって最適モデルが変わる（説明力重視なら SEM／SDM、予測力重視なら SPD／クリギング、AICフィッティングならまた別）。近傍の定義（4近傍か6近傍か）で順位が入れ替わる。空間交絡として、OLS で係数0.028と有意だった犯罪率（ボストン）の係数が、空間モデル導入後に標準誤差14.4個分動いた。結論は「課題設定（何のために分析するか）を定めてから手法を選ぶ」という基本に戻る。
  • 実務への転用: 検討中の太陽光発電・蓄電池物件の発電効率（イールド）・PL評価に応用。川口先生の紹介では、スライドは約150ページ、機械の誤りを21件発見、ランダム分割の交差検証は空間モデルを平均約18%過大評価、AICで1位のモデルは説明の適正では6位だった。
  • ゼミ活動の紹介: ポータル（過去資料・議論ログ）、DMM メールマガジン、Facebook グループ、川口先生の YouTube チャンネル。

11.7 パネル③ 川口先生「AI時代の専門家像（Statistical Model Thinker）」

  • ハルシネーションは確率モデルの性質であって、専門家レベルで議論する論点ではない。エージェントAIの4つの仕組み（①バイブコーディング ②テストタイムコンピュート ③エージェンティックグラウンディング ④モデルオーケストレーション）では、人間の仕事は「いつ検証させ、いつ方針を変え、いつ成功を宣言するか」の判断。
  • プログラミングはコンパイラ・テストで機械的に答え合わせできるが、統計解析では仮定の誤りや分析の分岐が整った結果に埋もれる。判断の問いは「間違っていたとき、自分が信じたいかどうかと無関係に露見するか」。出力がもっともらしく見立てに合うほど検証が省かれる（確証バイアス）。
  • 最新研究: データサイエンスエージェントは完全自律では参加者の中央値前後にとどまり、最良の結果は人間が方向転換を指示した共同作業から生まれた。因果効果が識別できないときに分析を棄却できるかの採点で、最上位モデルも0.28程度。
  • 予測は確かめられるが解釈は確かめられない。係数が空間交絡に吸われたとき、それが偏りの修正か消失かはどの検証も教えない。専門家の条件は、複数の依存構造を知る／モデルを批判的に解釈する／対象の性質で選ぶ（従来と同じ）＋主張を言語化する（新規）。企業の計画資本と個人の統計的モデル思考は、同じものを別の尺度で測っている。

11.8 パネル討論（鈴木さん・松前・会場）

  • 会場から、生成AI時代はネガティブ・ケイパビリティ（すぐ答えを出さず現場に向き合う力）が重要との意見。松前は、質の高い情報を取れるか・批判的に見られるかに近く、ネット上の公開データを集めるだけの仕事は相対的に価値が下がり、組織のコンテクストや現場知が価値になると応答。
  • 鈴木さん: 情報をまとめるだけの人は不要になり、ストーリーを作れる人の価値が上がる。修論の下書きをAIに書かせたが、ニッチな分析で先行研究がなく、書きたい内容と結果の解釈がずれた。
  • 川口先生: ビジネススクールで長年の悩みだった「基礎統計に授業を使い切ってしまう」問題が、生成AIで解けた。法学部出身の鈴木さんが半年〜1年で時空間統計の発表に到達したことが例。専門家の価値は上がるが、フェラーリに乗れない人との二極化・格差が生じる。4月以降、企業経営者・不動産会社経営者からの相談が増えたとのお話も。
  • 「ネガティブ・ケイパビリティとAIの高速・観察的アプローチは対立しないか」という質問には、ドメイン知識・メタ知識がないと疑えない、テストドライバー級の知識がなければフェラーリの性能は引き出せない、との回答。

11.9 第3部 全体討論（導入: 評価基準案）

  • AIで作業を速く終えることはもはや標準で、評価対象ではない。AI利用の代償を示す研究として、Microsoft Research（知識労働者319人: AIを信頼する人ほど批判的思考が減る）、ランダム化試験（1,200人超: AI支援で成績は上がるが、外すと下がり難問を諦めやすくなる）、Anthropic（Shen & Tamkin: 新しいライブラリの学習でAI利用者は概念理解・デバッグが劣る）が紹介された。
  • 評価の4軸: ①ゲートキーピング力（AIの誤りが機械的に露見する仕事かを見極め、進め方を切り替える）②モデル選択力（当てはまりでなく対象の性質から選ぶ）③主張の言語化力（成果物の主張を自分の言葉で語り責任を負う）④外部査読の設計力（事前基準にもとづく外部レビューを組む）。
  • 214人の実験で、AIの誤った作業計画を7割がそのまま受け入れたが、「この計画は何を仮定しているか」を問わせると63%に低下。Stanford の研究では、主要11モデルは人間より49%多く利用者の行動を肯定し、迎合的なAIとの1回のやりとりで自分が正しいという確信が強まる。→ 「信じたいかどうかと無関係に露見するか」を個人の心に任せず、事前基準と外部査読を組織の仕組みにする必要がある。
  • グレード: G1（出力をそのまま信じる）→ G2（自動露見を自問し進め方を切り替える）→ G3（モデル選択理由を自分の言葉で説明でき、依頼前に基準を固めている）→ G4（組織の業務を仕分け、査読の仕組みを設計できる）。AI時代の主戦場はG3。
  • 討論の4問: ①自分の仕事でAIの誤りは信じたいかどうかと無関係に露見するか ②AIに任せた分析で何を主張したことになるのか ③迎合的AIを好む利用者に、組織はどんな外部査読を制度にすべきか ④今回は違うのか。価値を持つのは「答えを出す力」か「問いを立てる力」か。
  • 会場からの意見: 産業革命は肉体、インターネットはホワイトカラー、AIは「ホワイトカラー→フィジカルAI→ブルーカラー」の2段階で、2000年のIT崩壊より長く深い影響になりそう／キャッシュ豊富な企業がレバレッジをかけて投資しているが、結果が読めない（データセンターは100兆円規模で保険がかけにくい）／最終需要の不在が問題で、供給のコストカットと中間需要ばかり。ITバブルもインターネット登場から最終需要が出るまで5〜6年かかった／ITバブルのときも収支は合わなかったが、20年経つと意味のあるものが実現した。AIも何かは実現するが、バブルなら調整は必要。
  • 川口先生の総括: 今日は結論が出なかったので、各自で「今回は違う」かを解釈してほしい。今後もこの形でネットワークを作りたい。
