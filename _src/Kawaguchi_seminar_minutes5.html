10.1 講話: 知識工学から生成AIへ、そして統計言語学

  • 川口先生ご自身の位置づけの説明から。ジョブズやゲイツと同世代で同じようにガレージでOSを開発していたが、彼らがアメリカにいたのに対し自分は土木分野にいたため、知識情報処理を不動産へ応用する方向に進んだ、という経緯。かつての「知識工学」はAIブームの中で消滅し、情報工学側に「知識情報処理」が残った。
  • 生成AIが復活した主因は自然言語処理の成功にある。NLPは一度行き詰まったが、統計言語学の登場で飛躍的に改善し、その流れで Word2Vec が出てきて現在の基盤になった。
  • Zipf則: 都市の規模順位と人口を対数プロットすると直線になる。小説の単語（トークン）の出現順位と頻度も同じくZipf則に従う。人間が作った言語・文章はすべてこれに従う。
  • 「意味」とは平行移動である: 自然に関する記事、不動産に関する記事とテーマ別にZipf則を描くと、傾きはほぼ同じで平行移動したグラフになる。この平行移動の差が「意味」である — これが Word2Vec の発想。Zipf則は一種の確率分布であり、したがって人間が書いたもの・話したことはすべて確率分布として表現できる。
  • いわゆる「確率的オウム」批判への反論の根拠もここにある。Word2Vec は「確率分布で意味を表せる」ことを数学的に示した論文である。一般には「国王 − 男性 + 女性 = 女王」という例で説明される。

10.2 IID と依存性 — グラム行列・カーネル・アテンション

松前から「Word2Vec までは腹落ちするが、そこからLLMがあれほど複雑なことをできるようになった飛躍が分からない」という質問。これに対するご回答が、本合宿の理論的な芯になりました。

  • 標準的な統計学は IID（独立同一分布） を暗黙の前提とする。ガウスは理論モデルを実データにぶつけ、残るノイズを確率的に扱うという発想（最小二乗法）で成功した。
  • IIDだけでもある程度の文章は生成できる。ある作家の小説からZipf則を推定し、その分布に基づいてランダムウォークで単語を生成すれば「小説らしきもの」はできる。ただし文脈依存を出したければIIDではダメで、依存を入れる必要がある。
  • 回帰係数の公式に立ち返る: β ハット ＝ (X'X)⁻¹X'Y。この X'X がグラム行列であり、その逆行列が分母に来る形で正規化されている。IIDの世界では X 同士は独立（多重共線性は排除すべきもの）で、依存関係は X と Y のあいだにしかない。
  • カーネル回帰はグラム行列を使うが、そのとき使うのは単なる説明変数ではなく特徴量（特徴空間）である。したがって LLM は「特徴のグラム行列＝内積＝依存関係」を使って処理している。これが「なぜ複雑なことができるのか」の答えにあたる。
  • 松前から「それがアテンション機構ということですね」と確認したところ、「アテンションはカーネルで代替できる、という理解でLLMのモデルは全部理解できていると思っている」とのご回答。カーネルは移動平均のようなもので、依存関係をどう表すかという問題に対する一つの答えである、という補足があった。
  • 1980年代と何が違うかというとウェブである。ウェブ上に存在しない知識・データはもう事実上ない。それを全部使って確率分布を推定すれば、あとは取り出す道具を作ればよい。

10.3 発表①: Boston住宅価格データ × CARモデル（鈴木 康太／松前が代読）

発表①スライド PDF（全24枚） PPTX 原本
  • 村上大輔氏のテキストとGitHub公開のRコードを利用。手順はOLSで重回帰 → 残差がIIDを満たさず空間的依存が確認される（Moran's I 検定）→ CARモデルを採用。
  • モデル選択: 19個の説明変数の総当たり → AICで選定 → 解釈可能性の制約として8つの制約を課し、2¹⁵通りの組み合わせから最終モデルを選定 → CARを指定し、Claude に ICAR / BYM / Leroux の3バージョンを出力させた。分析全体を Claude Code への指示のみで実施し、RStudio を起動していない。
  • 川口先生による定式化の訂正（重要）: 「残差に空間構造を仮定する」という言い方は正確でない。標準の回帰は Y = Xβ + ε で ε が残差でありIIDを仮定する。CARモデルは誤差項を ε（IID成分）と φ（空間構造成分）の2つに分解して、φ を式の右辺に見える化して書き出している。したがって φ は残差ではなく、空間ランダム効果という「仮定した構造」である。
  • φ は平均0の正規分布に従い、その条件付き期待値は隣接する住宅価格の平均に比例する — これが条件付き自己回帰（Conditional AutoRegressive）の意味。Xβ は固定効果でボストン全域に共通の価格形成関係を表し、φ は確率効果で i 番目の住宅の周辺だけの局所的な依存関係を記述する。
  • なぜ局所性が重要か: 通常の回帰は全体の平均を見るものであり、個別性を扱えない。情報が局所的に偏在している対象では平均の議論は役に立たない。代替手段として SAR（同時自己回帰）があり、右辺に γ × W·Y を入れて Y と Y の依存を表す。CAR と SAR は構造の入れ方の違いであり、テキストの各モデルは「どんな構造を仮定しているか」という観点で読むべきである。

10.4 発表②: 首都圏公示地価データによる空間モデル総当たり（松前）

発表②スライド PDF（全127枚・フル報告版） PPTX 原本

※ Web掲載版は当日投影版と同内容ですが、著作権に配慮し、村上テキスト第3章の書籍ページ画像（26枚目）を出典カードに差し替えています。

  • 課題意識は「どの場合にどのモデルを使えばよいか、というマニュアルを作ること」。テキスト付属のデータではなく、載っているモデルを一通り全部当てられるだけリッチなデータとして、東京・埼玉・千葉・神奈川の公示地価データを使用（緯度経度・各種距離が揃い、隣接関係も取れる）。
  • 出発点はOLSヘドニック。そこから残差診断（QQプロット、VIF、RESET検定、Breusch-Pagan検定、残差のMoran検定、セミバリオグラム）でIID仮定の破綻を確認したうえで、空間構造をどこで受け止めるかによってA/B/Cの3分岐するフローチャートを作成した。
    • A: 誤差項に置く — 隣接行列（ルーク型・クイーン型）を定義して SAR / SEM / SDM。滑らかに扱うなら回帰クリギング、SPDE、INLA
    • B: 係数に置く — 場所ごとに回帰係数が異なるとする GWR、VC-GAM
    • C: 欠落変数として扱う — 固有ベクトル空間フィルタリング（ESF）
  • 結果: AICではスプライン法を使ったGAMが最良適合。ただし「できそうなものはほぼ全部やるくらいの気持ちでやらないと、そのデータの立体感は分からない」というのが実感。
  • Claude Code の使い方: まず文章ですべて出力させる。データ選定の相談から投げ、テキストと前年の川口先生資料のPDFを与えて分析を依頼。Obsidianでテキストを管理し、Claude Code に R をインストールして実行させた。グラフを含め一文字も手入力していない。

10.5 AICの限界とアブダクション

  • 松前から「AICで選ぶと昨年の演習で教わったが、勉強してみるとネストされたモデル同士でないと比較が適切でないと分かり、では何を使えばよいのか困った」という問題提起。
  • 川口先生: AICが使えないとなると、次に来るのは「こういうモデルにしよう」という自分の発想である。演繹でも帰納でもなくアブダクション（仮定を置いて検証し、それを繰り返して真実に近づく）が重要になる。
  • 先生ご自身の不動産についての方法もアブダクションであり、何十年も仮定と検証を繰り返している。「論文を書く暇はない。自分が現実をチェックして、どれだけ真実に近づいたかを信じたい」。
  • 補足として、スプラインを使ったGAMは実質的にINLA（リンク方程式に落とすモデル）でもある、という指摘があった。

10.6 2つの統計文化 — β の不偏性 vs Y の予測精度（黒田先生）

黒田先生から、分析目的による文化の断絶についてのご指摘。本合宿でもっとも実務に効く論点でした。

  • 経済学・計量経済学: 目的は β の不偏推定。X が動いたとき Y がどれだけ動くかというメカニズムを知りたい。Y の予測性能にはほとんど関心がない。誤差項が空間的依存構造を持つことが問題になる主な理由は、それが X と相関していると不偏性を満たさなくなるからである。
  • データサイエンス・機械学習: 目的は予測精度（クロスバリデーション）。バイアスの有無は問わず、当たりがよいかどうか。
  • 川口先生の補足: この対立は赤池（1980年）に対して「統計学は予測のためのものだ」と反応した流れがあり、それがベイズのアプローチである。2000年に「2つの文化」の論文（Breiman）が出ている。生成AI登場後は「バイアスより当たればよい」に走っている面があり、それへの批判もある。
  • Bostonデータの出自: もともと環境経済学者（Harrison & Rubinfeld, 1978）が、大気汚染（窒素酸化物）に対するボストン市民の支払意思額を回帰係数から推定するために使ったもの。β 推定が本来の目的である。

10.7 診断的不確実性とステージング・ディスカバリー

リアルオプション学会でのご講演（ハイパースケーラーの企業価値評価）に接続する、合宿の中心テーマです。背景となる論文は 8/22ページに掲載しています。

  • 25年前、Amazon が出てきたときはリアルオプションで説明がつきそうだと言われた。しかし現在の Amazon はハイパースケーラーになっており、リアルオプションでは評価できない。ご講演のタイトルは学会に配慮して「リアルオプションの限界と拡張」としているが、実質的な主張は「リアルオプションの時代は終わった」。
  • リアルオプションが対応できるのは外的不確実性である。来週ゴルフに行くが雨が降るか晴れるか、といった外部環境が決めてくれるもので、待てば解消する。
  • 診断的不確実性は解消されない: 同じ実験をやっても A さんと B さんで解釈が違う。診断結果を正しく解釈できるかどうかの能力が企業価値を決める。
  • 社会科学は実験できない、という前提が変わった: ハイパースケーラーがやっているのは実験である。ウェブ上の情報を全部コントロールできる立場にいるため、仮説を立てて実験しチェックするサイクルが回る。TSMC も同様に、多数の半導体を実験的に出して成功パターンを見つけている。
  • Staging Discovery: 段階的な発見を連続して行える企業の価値は極めて高い。「どういうシークエンスで質問していけばよい結果にたどり着くか」がこれにあたる。
  • ラピダスへの含意: 診断的不確実性を解消する能力は、同じアセットを持っていても組織のインフラ（制度）と人的資本によって差が出る。不動産ならよい物件を持っていればよいが、ハイパースケーラー型の事業はそうではない。
  • 価値の所在が移った: 答えは機械が全部出してくれるので、ある意味で「答える価値」も「論文の価値」もない。問題は、その答えを作ったときの診断におけるクエスチョンが何であったか、どういうクエスチョンを連鎖して出していったかである。

10.9 Belsley『Regression Diagnostics』と異常値処理

なぜ Boston データを教材に選んでいるのか、という説明です。ここは先生の主張として強い温度感がありました。

  • Harrison & Rubinfeld の1978年論文は査読を通っているが、その後に統計学者から「最小二乗法ではダメだ」と指摘された。被説明変数が打ち切りデータになっており下方バイアスがある、などの問題がある。
  • Belsley（1980年）『Regression Diagnostics』（原題に "Diagnostic" が入る）に Boston の例が載っており、変数・式・推定結果まで示されている。日本語訳が事実上なく、日本ではほとんど説明されていない。
  • 重要なのはファットテール性。不動産価格（公示地価も Boston も）はファットテールなので最小二乗法を使ってはいけない。二乗すると大きい値・小さい値の寄与が過剰になり β 推定にバイアスが出る。そこで絶対値の和を最小化する（最小絶対偏差）方法があり、Belsley はそれと最小二乗を組み合わせた Huber 推定などを扱っている。
  • 異常値は間引かない: ケース・シラー指数のチームに東京の同じデータを渡して同時推定した経験から、彼らは異常値を除去しない。住宅データは貴重であり、異常値を除いたら不動産市場が分からなくなるから。代わりに分散が大きいものの重みを小さくして調整する。
  • これに対し日本では異常値を全部除いて推定する慣行がある。オフィスデータを「異常値だから」と間引き、しかも除外の事実を論文に書かずに査読を通した事例を、同じデータで再推定して発見したという話が語られた。望む結果になるようなデータ操作であり、開示もされていない。
  • 結論として「日本語で書かれているものを信じない」「1980年の教科書の内容が日本で50年近く教育されていないところに、翻訳文化の弊害がある」。

10.10 「問いを立てる能力」とメタプロンプト

  • セミナーの狙いはメンタルモデルの更新である。目的を早く解くことではなく、「依存性のあるデータに関する理解の枠組み」をバージョンアップすること。「このモデルを当てはめられるか」ではなく「このモデルは何を主張していて、他の選択肢とどう違うのか」を自分で学習する。
  • ガバナンス上の警告（最重要）: 出力が無効性を告げない領域がある。パネル固定効果もSARも空間ラグもクリギングのバリオグラムも、推定は必ず収束して整った出力を返す。依存構造を誤って書き込んでも警告は出ない。したがって「これは合っているか」をAIに聞いても意味がない。
  • 佐々木さんの質問「このセミナーで、出力が間違っていた場合、それは私の意図と無関係に露見するように仕組まれているか」に対して、川口先生: Boston データは答えが分かっており、それを書いたテキスト（Belsley）が存在するので、比べれば間違いは分かる。わざわざ露見の仕掛けを別途作る必要はない。
  • 育成仮説: 非専門家に自動化システムを実演で見せ、説明し、自ら使わせ、既知の欠陥を含む事例で判断の成果を突き合わせる。これを反復すれば受講者は教える側になる。補強すべきは判断過程を言語化してメタ認知的シグナルとして評価すること。
  • Why / What / How: 「How の部分が全部できてしまい、Why と What を考えられる知識が問われる時代になった」という整理。川口先生はこれを金融工学史に接続された — ブラック・ショールズ型の金融工学は「確率過程が分かっている」という前提から出発しており、リーマンショックが突きつけたのは「確率分布がどれか分からない」状況だった。生成AI後の新しい金融工学は「どんな確率仮定を置けばそこに行き着けるか」を問う段階にある。それが診断的不確実性である。
  • エキスパートは育つのか: 訳の分からない計算を手でやっているうちに肌感覚が身につき、バグ取りの過程で気づきが生まれる — その段階を飛ばして、いきなり整った計算結果が出てきたときに「これはおかしい」と気づけるのか、という懸念が共有された。
  • モデル思考: モデルは「単純化」「数学的アナロジー」「探索的な人工的構築物」の3つに分かれる。Y = Xβ は β が時間不変という単純化であり、β が変化するとすれば状態空間モデルになる。一つのモデルは一本のろうそくにすぎず、象の鼻だけを照らしても全体は分からない。複数のろうそくを近づける＝複数のモデルを試すことが「モデルで考える」ということ。
  • 統計的モデル思考の定義（川口先生の言葉）: 一つのデータに対して複数の依存構造の書き方があることを知り、それぞれが何を単純化し・何になぞらえ・何を人工的に構築したものかを区別でき、当てはまりの数字ではなく、対象の性質からモデルを選んだことで何を主張したかを自分の言葉で述べられること。実装はAIに任せてよいが、この主張の言語化だけは自分で行う。

10.11 著作権と書籍の電子化

  • AI に書籍を読ませる際の運用が話題に。川口先生は村上テキストを業者に依頼して OCR スキャンし、PDF を Markdown に変換して AI に読ませている。「直接読ませたほうが回答精度が上がる」一方、知的生産の結晶を盗んでいる感覚があるとして、1冊は裁断・電子化し、もう1冊を購入するという運用にされている。
  • 著作権法の観点では、再配布せず私的利用にとどめれば問題は生じにくい、という整理が示された。（この整理に沿って、本ページ掲載の発表②Web版でも書籍ページの画像は差し替えています。）
  • 逆方向のリスクの指摘もあった。自分の書いたテキストを AI に評価させると「同じ内容が2回書かれている」「この段落は説明が分かりにくい」といった指摘が返ってくる。第三者がスキャンして AI に評価させ、その誤りをネット上に出す事態もありうるため、事前に自分でプロテクト（潰し込み）をかけている、とのこと。

10.12 NVIDIA の循環取引と J-REIT 外部運用スキームの類似

当日の新聞記事を Claude に読ませた例として紹介されました。10月のシンポジウムへの接続点でもあります。

  • NVIDIA がやっていること（顧客に資金を出させて GPU を買わせる構造）は J-REIT の外部運用スキームに似ているのではないか、という問いを立てたところ、Claude が比較表まで含めて「よく似ている」と回答した。
  • J-REIT の場合: 子会社を作って不動産を下ろす構造は不正ではないが利益相反の疑いがある。残価が読めない資産で外部運用スキームを組むのは危うい。そこで不動産鑑定評価を入れて第三者に残価を評価させる仕組みが導入された。
  • NVIDIA の場合: 実物投資としては合理的だが、資金調達構造がすでに実需の検証能力を上回っている。銀行・プライベートクレジット・保険を巻き込んだ債務構造が危うくなっている。
  • 10月への接続: ハイパースケーラーは問いを立てる能力で診断的不確実性を解消し、実験的投資によって成長している。赤字でも高いバリュエーションがつくことはバブルではなく説明可能である。しかしその一方で、資金調達側には昔の J-REIT と同じ構造があり、資産の評価者を入れない限りリスクが見えないという問題がある。

決定事項

  1. 発表②の分析対象データはテキスト付属データではなく、東京・埼玉・千葉・神奈川の公示地価データとする（一気通貫でモデルを全部当てられるリッチさを優先）。
  2. モデル選択の基準として AIC は万能でない（非ネストモデル間では比較不能）。以降はアブダクション（仮定 → 検証の反復）による選択を基本とする。
  3. 分析実装（Rコードの作成・実行・デバッグ）は Claude Code に委ね、人間はモデルの定式化・仮定の明示・診断結果の解釈と言語化に集中する。ただし判断過程の言語化だけは人間が行う。
  4. Claude Code に走らせる際は CLAUDE.md に禁止事項（変数を勝手に増やさない等）を明記し、「エラーが出れば修正して通るまで繰り返す」まで指示に含める。
  5. リアルオプション学会でのご講演の演題は「リアルオプションの限界と拡張」とする。
